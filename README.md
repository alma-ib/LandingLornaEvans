# Landing Lorna Evans

Esta es una landing page sencilla para Lorna Evans. Está hecha con React y Vite.

## Cómo correrlo en tu compu

1. Instalá las cosas necesarias:
```bash
npm install
```

2. Prendé el servidor de desarrollo:
```bash
npm run dev
```

¡Y listo! Abrí el link que aparece en la terminal y ya la podés ver.
